# Machine Learning: The Complete Beginner's Guide — Companion Code

All companion scripts referenced in the book, organized by chapter (`code/ch01/` ... `code/ch17/`, plus `code/project/`, `code/templates/`, `code/appendix/`) exactly as the book names them.

## About this repository

This repository was built by auto-extracting the code and hands-on labs from the printed book. Extraction was done from the book's PDF text, so:

- Lab write-ups (topology, steps, verification commands) are reproduced in full and should match the book closely.
- Python scripts were recovered from the book's text and, where the PDF's layout scrambled the original indentation, auto-repaired. Files are flagged in `EXTRACTION_NOTES.md` as passed or needing a manual check.
- Please review before using in a classroom or handing to students.
