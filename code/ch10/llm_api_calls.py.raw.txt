Fine-Tuning vs. Prompting: When to Do Each
Given a pre-trained LLM, you have two ways to adapt it for your task: prompting (no
training required) or fine-tuning (further training on your specific data). Choosing
between them depends on your task, data, and resources.

 Approach                                             When to Use It

 Zero/Few-shot prompting                              Task is common (translation, summarization,
                                                      Q&A). You have fewer than ~100 examples. You
                                                      need to change the task frequently. Cost: per-
                                                      token API fees only.
 Prompt engineering                                   Task requires specific output format. Chain-of-
                                                      thought helps (math, logic). Role/persona
                                                      matters. Still no training required.
 Fine-tuning                                          Task is highly specialized (medical, legal,
                                                      domain-specific). You need consistent
                                                      format/style. You have 1,000+ examples.
                                                      Privacy requirements prevent sending data to
                                                      APIs.
 RAG (retrieval-augmented)                            You need up-to-date information. You have
                                                      large document collections. You need citations
                                                      and source attribution. Avoids hallucination on
                                                      facts.

Approach                                      When to Use It
Full pre-training                             Only for organizations with massive compute
                                              budgets. Necessary only when domain is so
                                              specialized that general internet text is
                                              insufficient (e.g., specialized scientific
                                              language).

Key Terms
Term                                          Meaning

Attention                                     A mechanism that lets each token weigh every
                                              other token when building its meaning.
Query, key, value                             Three vectors per token: what it looks for, what
                                              it offers, and what it passes on.
Transformer                                   A network built from attention layers; the basis
                                              of modern language models.
Encoder / decoder                             Encoders (like BERT) read text to understand it;
                                              decoders (like GPT) generate text token by
                                              token.
API                                           A way for your code to send a request to a
                                              hosted model and receive its reply.
