  Common Questions
  Q: Why is BERT bidirectional and GPT unidirectional?
  A: BERT is designed for understanding tasks where you have the complete text
  (classification, Q&A). It reads left AND right to build the richest possible
  representation of each word. GPT is designed for generation tasks where you must
  produce the next word without seeing future words. A generation model that could see
  future words would be ‘cheating’ — it is not generating, it is copying.
  Q: How do tokenizers handle words they have never seen?
  A: Subword tokenizers like BPE split unknown words into known subword units. A
  name such as ‘GPT-4’ might be split into a few pieces (the exact split depends on the
  tokenizer’s vocabulary, so check it yourself with a tokenizer, as the code below does).
  This means any word, including new proper nouns, technical terms, or invented
  words, can always be represented — you just need more tokens to represent rare
  words.
  Q: Why do transformer models have a maximum context length?
  A: Self-attention has O(n²) computational complexity — doubling the sequence length
  quadruples the computation. A 512-token sequence requires 512² = 262,144 attention
  computations. A 128,000-token context requires 16 billion. Extending context length
  requires architectural innovations like sparse attention, sliding window attention, or
  linear attention mechanisms.

Text Preprocessing: From Raw Text to Model Input
Before any NLP model can process text, the raw text must go through a preprocessing
pipeline. Understanding this pipeline prevents a whole class of bugs and performance
problems.

Tokenization: Splitting Text Into Units
Tokenization splits text into the smallest units the model processes. There are three
levels:
     •    Word-level: split on spaces and punctuation. Simple but creates large
          vocabularies and cannot handle misspellings or new words (‘gangster’ and
          ‘gangsters’ are different tokens).
     •    Character-level: treat each character as a token. Small vocabulary (26 letters
          + punctuation) but very long sequences, and it takes many tokens to
          represent meaningful concepts.
     •    Subword (BPE, WordPiece, SentencePiece): the modern standard. Split
          words into frequent subword units: ‘unbelievable’ → [‘un’, ‘##believe’,
          ‘##able’]. Rare words are decomposed; common words remain whole.
          Handles new words gracefully. Vocabulary size: 30,000-50,000 tokens. Used
          in all modern LLMs.

Tokenization is shown in huggingface_basics.py above: print the pieces and the integer IDs for yourself
rather than trusting a hand-written list.

Padding and Truncation: Making Sequences the Same Length
Neural networks require all inputs in a batch to be the same length (for efficient
matrix operations). Short sequences are padded with a special [PAD] token; long
sequences are truncated. An attention mask (1 for real tokens, 0 for padding) tells the
model to ignore padded positions.

Padding and the attention mask are the last part of huggingface_basics.py above.
